# HIPG Publishing Website Sample

Static client-preview website for HIPG Publishing.

## Files

- `index.html` - website markup
- `styles.css` - responsive publisher-style design
- `script.js` - mobile menu, category filters, book modals, and local likes
- `.nojekyll` - lets GitHub Pages publish the static files as-is

## GitHub Pages

After pushing this repository to GitHub:

1. Open the repository on GitHub.
2. Go to **Settings** > **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**.
5. Save, then wait for GitHub to provide the public Pages URL.
